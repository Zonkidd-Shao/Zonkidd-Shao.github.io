Markdown 写作完全指南

2026 年 7 月 20 日 · 1 分钟阅读
# Markdown # 写作 # 效率

Markdown 的设计哲学很简单：让作者专注于内容，而不是排版。它用纯文本表达结构，渲染交给工具。

为什么是 Markdown

  • 通用：GitHub、Notion、微信编辑器都支持
  • 可移植：纯文本，永远可读，永远可迁移
  • 专注：写作时不打断思路
  • 版本友好：和 Git 天然契合
