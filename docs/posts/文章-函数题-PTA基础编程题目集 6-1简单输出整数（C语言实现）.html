PTA基础编程题目集 6-1简单输出整数（C语言实现）

2026 年 8 月 7 日 · 2 分钟阅读
# PTA # C语言 # 函数题 # 算法

摘要：本文是 PTA 函数题“6-1 简单输出整数”的题解，涵盖题目描述、函数接口定义及 C 语言实现，展示 for 循环遍历与顺序打印的基本方法。

题目描述

本题要求实现一个函数，对给定的正整数 N，打印从 1 到 N 的全部正整数。

函数接口定义：

void PrintN ( int N );

其中 N 是用户传入的参数。该函数必须将从 1 到 N 的全部正整数顺序打印出来，每个数字占 1 行。

裁判测试程序样例：

#include <stdio.h>

void PrintN ( int N );

int main ()
{
    int N;

    scanf("%d", &N);
    PrintN( N );

    return 0;
}

/* 你的代码将被嵌在这里 */

输入样例：

3

输出样例：

1
2
3

解题思路

这道题的核心是利用 for 循环实现有序区间整数的逐个输出。

核心问题分析

给定正整数 N，需要按升序打印闭区间 [1, N] 中的所有整数。每个整数独占一行。题目隐含约束：N 为正整数（输入保证），输出顺序必须严格从 1 递增到 N。

算法原理说明

使用 for 循环作为控制流，循环变量 i 从 1 开始，每次自增 1，直到 i > N 时终止。循环体内每次调用 printf 输出当前 i 的值并换行。这是最直接的线性遍历方法，无需额外数据结构。

具体计算步骤

  1. 声明循环控制变量 i
  2. 初始化 i = 1，循环条件 i <= N，每次循环后执行 i++
  3. 循环体：调用 printf("%d\n", i) 打印当前整数并换行
  4. 循环结束后函数隐式返回（void 函数无需 return）

函数部分实现

/* 6-1 简单输出整数
 * 函数：PrintN
 * 功能：从 1 到 N 顺序输出整数，每个数占一行
 * 参数：N — 正整数，表示输出区间的上界
 * 实现原理：for 循环线性遍历。
 *   - 循环变量 i 从 1 开始，每次 i++，直到 i > N 退出
 *   - 每轮调用 printf 输出 i 并换行
 * 时间复杂度 O(N)，空间复杂度 O(1)
 */
void PrintN(int N)
{
    int i;
    for(i = 1; i <= N; i++)
        printf("%d\n", i);
}

完整代码实现

/* ============================================
 * 6-1 简单输出整数
 * 题目：实现函数 PrintN(int N)，从 1 到 N 顺序输出整数，
 *       每个数占一行。
 * ============================================ */

/* --- 头文件引入 --- */
#include <stdio.h>      // 提供 printf、scanf 等标准输入输出函数

/* --- 函数声明 --- */
void PrintN(int N);     // 告诉编译器：后面会定义这个函数，现在可以先使用

/* --- 主函数：程序入口 --- */
int main()
{
    int N;              // 声明整型变量 N，用于存放用户输入的正整数

    scanf("%d", &N);    // 从标准输入读取一个整数，存入变量 N

    PrintN(N);          // 调用 PrintN 函数，将 N 作为参数传入

    return 0;           // 程序正常结束，返回 0 给操作系统
}

/* --- PrintN 函数实现：从 1 到 N 逐个输出 --- */
void PrintN(int N)
{
    int i;              // 声明循环变量 i

    // for 循环：i 从 1 开始，每次循环后 i 自增 1，直到 i > N 时退出
    for (i = 1; i <= N; i++)
    {
        printf("%d\n", i);  // 输出当前整数 i，并在末尾加上换行符 \n
    }

    // 循环结束后函数自动返回，无需显式写 return
}

代码流程说明

1. 头文件引入与函数声明

  • #include <stdio.h> 引入标准输入输出库，提供 printf 和 scanf
  • void PrintN(int N) 函数原型声明，告知编译器该函数的签名

2. 主函数：读取输入（main 第 75-84 行）

  • 声明变量 N 用于存储输入的正整数
  • scanf("%d", &N) 从标准输入读取整数到 N
  • 调用 PrintN(N) 执行打印

3. PrintN 函数：循环打印（第 87-98 行）

  • 声明循环变量 i
  • for 循环三段式：初始化 i = 1、条件 i <= N、步进 i++
  • 循环体：printf("%d\n", i) 输出整数并换行

4. 程序结束

  • main 函数返回 0，程序正常退出
