zonkidd-blog · 个人博客系统

基于 GitHub Pages + Node 构建脚本的极简博客，Markdown 写作，一行命令构建部署。

  • 技术栈：Node.js / marked / highlight.js
  • 特点：零依赖服务端、亮暗主题、代码高亮、栏目可扩展
git clone https://github.com/Zonkidd-Shao/zonkidd-blog
npm install && npm run build
